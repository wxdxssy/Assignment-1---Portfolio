Hangman Game

This project was a culminating assignment for INFR1101. My group and I decided to recreate the popular hangman game on python for this project. We had both a single and multiplayer mode for people that wanted to play with friends! We incorporated many aspects learned in the course such as file handling, loops, and functions.

Banking System

This project was a culminating assignment for INFR2141. My group and I decided to create a banking system with traditional banking features using python. Individuals can deposit, withdraw, transfer, check balances, and apply for loans. We used inheritance, polymorphism, encapsulation, and abstraction aspects which were learned throughout the course.

INFR2411 Case Study

For this project my group and I were tasked with a mock scenario of connecting a company's 3 corporate offices to the same network. This was done by creating a simulated enviornment of packet tracer and enabling various networking protocols that we learned throughout the semester. This included BGP, VLAN's, etherchannels, trunking, and VTP. Lastly, we had to come up with a creative solution on how to remotely access the network while mainting network integrity.

Napkin Design

This was an assignment for BUSI1600 and was called a napkin design as it was meant to be a rough estimate as to how much revenue and expenses a business we were to start may have. The irony of the assignment was that once I started it, I realized that even simplifying a business to a napkin design, there were still many complexities in the basics of a business.
